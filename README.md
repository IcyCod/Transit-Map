# Transit Map

A front-end-only tool designed which allows user to  **suggest, gather and compare** stations and lines — on as many **maps** as you like (Klang Valley ships as the default map).

By downloading whole source codes and visit index.html in the directory (folder) in a browser, you can work without relying this page too. However, modern browsers are not letting you to successfully load it due to same-origin policy. You can either bypass them in browser settings (make sure that you know what you are doing, but OpenStreetMap will not load properly), or run a simple local server to host as instructed when you opened index.html directly.

## ⚠ Work-in-progress project

The information in provided maps are still incomplete and may be giving wrong information. You are welcomed to help update and correct them.

## Suggestion or fantasy maps

There will be a map for collecting stations and lines suggested by the other, or those fantasies, which information will be accepetd via pull requests. Maps with special purposes or designs are welcomed too.
